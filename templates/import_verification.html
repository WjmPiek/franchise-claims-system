Import Verification

Check what is saved and whether it matches the original uploaded files. These checks read data; they do not replace or recalculate it.

How to read the results

Not checked: an import exists, but its original file has not yet been independently compared with the saved records. Verified — totals match: the original file checksum, row counts and amounts match. Review notes still need attention. Needs correction: a difference was found, or the archived original could not be checked.

Missing months below identify gaps in the selected calendar period. To prove every expected file was supplied, also compare this list with your own source-file list.

Large monthly files are checked in the background. You can leave this page and return later.
