Which import should I use?

The dates above filter reports, not uploads. Every applicable row in each selected monthly file is processed.

Direct monthly source: use the complete Direct CSV or converted Excel for insurer payovers, AUL loading files, vouchers and product / policy detail.

Policy / premium Excel: currently supplies the Claims financial dashboard, commissions and book value. It does not yet receive the saved Direct preparation automatically.

Claims paid Excel: supplies claim amounts and reconciliation. Keep importing it separately.

Use one file per month in each required source. Do not import the same premiums twice into one source. Preparing a Direct month replaces that saved Direct month.
